# Executive Governance Templates

Reusable working artefacts supporting the frameworks in this repository. Adapt them to context; they are not universal prescriptions.

| Template | Purpose |
|---|---|
| [RACI matrix](raci-matrix.md) | Clarify roles and accountability |
| [KPI dictionary](kpi-dictionary.md) | Define measures consistently |
| [Benefit profile](benefit-profile.md) | Specify baseline, target, owner and attribution |
| [Initiative canvas](initiative-canvas.md) | Summarise the initiative mandate |
| [Weighted scoring matrix](weighted-scoring-matrix.md) | Compare discretionary options |
| [Decision record example](decision-record-example.md) | Show a completed illustrative decision |
| [KPI reference](kpi-reference.md) | Define open-source, sustainability and AI/RAG measures |
| [Governance forums](governance-forums.md) | Define decision classes, forum remits and charters |
| [Escalation and status](escalation-and-status.md) | Set tolerances, write an escalation brief and report status |
| [Strategic dependency register](strategic-dependency-register.md) | Make cross-initiative dependencies, owners and exit options visible |
| [Open-source assessment](open-source-assessment.md) | Score options, review governance health, plan contribution and test exit readiness |
| [AI/RAG use-case assessment](ai-rag-use-case-assessment.md) | Assess a use case, register sources, plan evaluation and record decision gates |
| [Infrastructure capacity decision](infrastructure-capacity-decision.md) | Compare capacity options and record energy, water and service assumptions |
| [Executive checklists](executive-checklists.md) | Run copyable checklists before decisions, at reviews and in operation |

Use the initiative canvas to frame the problem, score only discretionary options, record the decision and conditions, then define KPIs and benefits before delivery. Mandatory obligations must be identified separately from discretionary scoring.
